# Zone Staff Dashboard

## Purpose
Give volunteers a simple operational view without global admin access.

## Mobile view
- Zone name
- Current interactions
- Experience completions
- Coins spent
- Recent activity

## Permissions
Staff can only operate assigned zones.

## Optional verification
A staff member may mark an experience as manually verified only if the experience configuration permits it. Manual actions are audited.

## Failure support
Show simple attendee support tools:
- verify VIBE ID
- view completion status
- report issue

Do not expose wallet editing.
